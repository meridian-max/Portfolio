# AGENTS.md

## Project Goal
Build a premium portfolio website for a 3-person freelance product engineering team offering websites, ML systems, web apps, software, automation, and deployment.

## Preferred Stack
Use Next.js, TypeScript, Tailwind CSS, shadcn/ui, MDX, Vercel, and Framer Motion or GSAP unless the project clearly requires something else.

## Positioning
Present the team like a small product-engineering studio, not three separate resumes.
Lead with business outcomes, delivery capability, and proof.

## Content Rules
Every featured project should include:
- Problem
- Solution
- Our role
- Tech stack
- Screenshot, demo, or product visual
- Measurable result when available
- Client quote when available

## Homepage Priorities
Keep the homepage order focused on:
- Hero
- Proof bar
- Services
- Featured case studies
- AI and ML capabilities
- Web and software capabilities
- Process
- Team
- Testimonials or proof
- Contact CTA

## Quality Rules
Before finalizing major website changes:
- Run lint
- Run typecheck
- Run build
- Check mobile responsiveness
- Check accessibility basics
- Check contact flow
- Check SEO metadata
